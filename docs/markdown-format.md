# ResumeCraft Markdown 格式规范

ResumeCraft 使用「**YAML front matter + 约定式标题分节**」的 Markdown 作为简历源文件。
数据与样式解耦：正文只管内容，样式/模板通过 front matter 声明。

---

## 一、整体结构

```markdown
---
template: minimal
layout: full
theme:
  accent: "#111827"
---

# 姓名

**标签**：值
**标签**：值

> 个人简介 / 自我评价

## 区块名

### 条目标题 · 时间
**副标题**
- 要点一
- 要点二
```

---

## 二、Front matter（元信息，不渲染进正文）

文件最顶部用 `---` 包裹的 YAML，定义样式与模板：

| 字段 | 类型 | 说明 | 默认 |
|------|------|------|------|
| `template` | string | 使用哪个模板（minimal/gradient/mono/dark） | minimal |
| `layout` | string | 布局（split 双栏 / full 单栏） | split |
| `theme` | map | CSS 变量覆盖，如 `accent`、`bg`、`card` | 空 |
| `pdf` | map | PDF 导出参数（page_size/margin） | 空 |

示例：
```yaml
---
template: dark
theme:
  accent: "#3fb950"
pdf:
  page_size: A4
  margin: 10
---
```

> 主题色变量可覆盖：`--bg` `--card` `--text` `--muted` `--line` `--accent` `--tag` `--proj-bg`。

---

## 三、正文约定

### 1. 一级标题 `#`：姓名

```markdown
# 张三
```

### 2. 简介区（姓名之后、第一个 `##` 之前）

- `**标签**：值` → 联系方式等字段（如 求职方向/电话/邮箱/所在地）
- `> 引用` → 自我评价/个人简介

```markdown
**求职方向**：前端工程师
**所在地**：上海
**电话**：138-XXXX-XXXX

> 四年 Web 前端开发经验……
```

### 3. 二级标题 `##`：区块

支持任意区块名，解析器自动识别以下特殊区块：
- `工作经历` / `教育背景`：条目+要点列表
- `项目经验` / `项目`：条目+简介（网格卡片）
- `专业技能` / `技能`：`**类别**：技能值` 列表 → 标签流

### 4. 三级标题 `###`：条目

```markdown
### 公司名 · 2023.7 - 至今     ← 标题 · 时间（`·` 分隔，可带标签）
**前端工程师**       ← 副标题（仅非项目区块）
- **要点引导词**：详细描述      ← 要点
```

标签（如 `负责人`）用反引号包裹：
```markdown
### 组件库建设 `负责人`
```

---

## 四、区块渲染差异

| 区块名 | 渲染方式 |
|--------|---------|
| 工作经历 / 教育背景 | 竖排条目：标题+时间+副标题+要点列表 |
| 项目经验 / 项目 | 两栏卡片网格：标题+标签+简介 |
| 专业技能 / 技能 | 标签流：`**类别**：值` 自动拆分 |

---

```markdown
# 张三

**所在地**：上海

> 四年 Web 前端开发经验……

## 工作经历

### 某互联网公司 · 2020.5 - 至今
**前端工程师**

- **核心项目**：搭建 Vite + TypeScript 脚手架，构建时间缩短 70%

## 项目经验

### 组件库设计 `负责人`
基于设计系统沉淀 30+ 可复用组件，统一多项目规范。

## 专业技能

- **系统运维**：Linux / Windows / RAID
- **网络**：TCP/IP / 网络排查
```
